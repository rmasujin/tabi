⚙️ GitHub設定

GitHubのPersonal Access Tokenを入力してください（初回のみ）

トークンの作成: GitHub → Settings → Developer settings → Personal access tokens → Generate new token

🚀 Vercel Deploy Hook

Vercel Deploy Hook URLを入力してください

Hook URLの作成: Vercel Dashboard → プロジェクト → Settings → Git → Deploy Hooks → Create Hook
