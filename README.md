# Wedding Site

結婚式ウェブサイト - RIKI & KANAMI

## 概要

モバイルファーストで設計された結婚式用のウェブサイトです。

## 機能

- **HOME** - ウェルカムフォトと投稿のタイムライン
- **MENU** - 料理とドリンクのメニュー
- **SEATS** - 席次表（マップ/一覧表示）

## 使い方

ブラウザで `index.html` を開くだけで動作します。

```bash
# ローカルで開く
open index.html
```

## ファイル構成

```
├── index.html     - メインHTMLファイル
├── styles.css     - スタイルシート
├── app.js         - JavaScript（画面遷移）
└── assets/
    └── logo.png   - ロゴ画像
```

## 技術スタック

- HTML5
- CSS3
- Vanilla JavaScript
- レスポンシブデザイン
- モバイル最適化
